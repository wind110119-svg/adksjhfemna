Word Garden（英文單字遊戲）PWA 安裝說明

這個資料夾放到任何 HTTPS 網站空間即可（例如 GitHub Pages、Netlify、Cloudflare Pages）。
用手機或平板開啟網址後：
  iPhone / iPad：Safari 分享按鈕 →「加入主畫面」
  Android：Chrome 選單 →「安裝應用程式」或「加到主畫面」
  電腦：Chrome / Edge 網址列右側的安裝圖示
安裝後可完全離線使用。學習紀錄存在各裝置本機，請用「家長設定 › 備份與還原」轉移。

「WordGarden_單檔版.html」只適合在電腦上用：用 Chrome 或 Edge 開啟即可離線遊玩，學習紀錄存在該瀏覽器。
請固定放在同一個位置、用同一個瀏覽器開啟。手機請改用上面的網址安裝方式（手機直接開本機 HTML 檔，iPhone 不會執行程式，Android 可能存不住紀錄）。
